# Трассировка компетенций КРМ 3.0

Первоисточник кодов и названий: [data/krm-v3.0.xlsx](../data/krm-v3.0.xlsx) (лист «Профессиональные»). Формулировки компетенций переносятся **без изменения смысла**.

## Официальные названия блока BD

| Код | Направление компетенции (КРМ) |
|---|---|
| BD-1 | Предварительный анализ данных |
| BD-2 | Понимание (интерпретация) данных |
| BD-3 | Хранение данных |
| BD-4 | Обработка больших данных |
| BD-5 | Дополнительные технологии организации инфраструктуры больших данных |

## BD-3.2 и модуль 4

В КРМ индикатор BD-3.2 относится к технологиям хранения **неструктурированных / слабоструктурированных** данных и оценивается на уровнях Б / С / П (от знакомства с классами хранилищ до организации доступа и структур для больших объёмов).

В курсе модуль 4 использует **средний (С)** уровень этого индикатора: студент обосновывает архитектуру DWH / Data Lake / Lakehouse / Fabric / Mesh, явно включая зоны и типы данных, для которых нужна схема-on-read, объектное и NoSQL-подобное хранение, а не только классический реляционный DWH (он закрывается модулем 3 / BD-3.1). Таким образом BD-3.2 здесь — не «любая архитектура КХД вместо NoSQL», а выбор корпоративной архитектуры **с учётом** неструктурированного слоя и соответствующих технологий.
